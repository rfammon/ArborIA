## Code Style Guidelines

### Imports and Modules
- Use ES6 modules with named exports
- Import order: standard library, third-party, local modules
- Group imports by category with blank lines

### Formatting
- 4-space indentation
- No semicolons (optional but consistent)
- Single quotes for strings
- Template literals for dynamic strings

### Types and Naming
- camelCase for variables, functions, and methods
- PascalCase for classes and components
- UPPER_CASE for constants
- Descriptive names in Portuguese (Brazilian)

### Error Handling
- Use try/catch blocks for async operations
- Show user-friendly error messages via showToast()
- Log errors to console for debugging

### General Patterns
- Async/await for asynchronous code
- Arrow functions for callbacks
- JSDoc comments for public functions
- Debounce for performance-critical UI events
